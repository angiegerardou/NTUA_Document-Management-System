MediaLab Documents - Document Management System

Αγγελική Γεράρδου, Α.Μ. 03120110

Το MediaLab Documents είναι μια desktop εφαρμογή διαχείρισης εγγράφων, γραμμένη σε Java με γραφικό περιβάλλον JavaFX. Τα δεδομένα αποθηκεύονται σε αρχεία JSON, τα οποία διαβάζονται και γράφονται με τη βιβλιοθήκη Jackson.

Η εφαρμογή έχει τρεις ρόλους χρηστών. Ο απλός χρήστης βλέπει τα έγγραφα των κατηγοριών στις οποίες έχει πρόσβαση, κάνει αναζήτηση και μπορεί να παρακολουθεί έγγραφα για να ενημερώνεται όταν αλλάζουν. Ο author μπορεί επιπλέον να δημιουργεί, να τροποποιεί και να διαγράφει έγγραφα, καθώς και να βλέπει την τρέχουσα έκδοση ενός εγγράφου και έως δύο προηγούμενες. Ο admin έχει όλες τις δυνατότητες του author και επιπλέον διαχειρίζεται τους χρήστες και τις κατηγορίες.

Κάθε αλλαγή σε ένα έγγραφο αποθηκεύεται ως νέα έκδοση. Όταν ο χρήστης συνδέεται, εμφανίζεται ειδοποίηση για όσα έγγραφα παρακολουθεί και έχουν αλλάξει από την τελευταία φορά που τα άνοιξε. Τα δεδομένα αποθηκεύονται όταν ο χρήστης πατήσει Exit ή κλείσει το παράθυρο.

Ο κώδικας βρίσκεται στον φάκελο DocumentManageSystem/src/main/java/documentsystem και χωρίζεται στα πακέτα domain (οι οντότητες), managers (η λογική της εφαρμογής), storage (φόρτωση και αποθήκευση των JSON) και ui (οι οθόνες). Τα δεδομένα βρίσκονται στον φάκελο DocumentManageSystem/medialab, στα αρχεία users.json, documents.json και categories.json.

Για να τρέξει η εφαρμογή χρειάζεται JDK 24 ή νεότερο και Maven. Από τον φάκελο DocumentManageSystem εκτελείται η εντολή mvn clean javafx:run. Από το IntelliJ IDEA, η εφαρμογή τρέχει από το Maven panel με την εντολή javafx:run του plugin javafx. Η εφαρμογή πρέπει να εκτελείται από τον φάκελο DocumentManageSystem, ώστε να βρίσκει τον φάκελο medialab.

Ο προεπιλεγμένος λογαριασμός διαχειριστή είναι medialab με κωδικό medialab_2025.

Περισσότερες λεπτομέρειες για τη σχεδίαση και τις παραδοχές υπάρχουν στην αναφορά PDF της εργασίας.
